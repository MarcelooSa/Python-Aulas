# SmartList - Sistema de Gestão de Compras

## 🎯 Sobre o Sistema
O **SmartList** é uma aplicação web desenvolvida em Python/Streamlit para controle inteligente de compras do dia a dia, ajudando usuários a organizarem listas, controlarem orçamentos e analisarem gastos mensais.

## 🚀 Funcionalidades Principais
- **Cadastro/Login**: Sistema completo de autenticação com validações
- **Gestão de Itens**: Adicionar, editar, excluir e marcar itens como comprados
- **Controle Orçamentário**: Definir limites mensais e receber alertas
- **Comparação Mensal**: Analisar gastos entre diferentes meses
- **Exportação Excel**: Gerar relatórios formatados automaticamente
- **Histórico**: Acompanhamento completo de compras

## 🔧 Tecnologias
- **Python** com **Streamlit** para interface web
- **OpenPyXL** para exportação Excel
- **Session State** para persistência de dados
- **CSS** para personalização visual

## 📊 Atendimento aos Requisitos
✅ **MVP Obrigatório:**
- Cadastro de itens (nome, quantidade, preço)
- Cálculo do valor total
- Alertas de orçamento ultrapassado

✅ **Evolução:**
- Marcação de itens comprados
- Comparação mês a mês
- Sistema completo de login/cadastro
- Exportação para Excel

## 🎯 Benefícios
- **Economia**: Controle real de gastos
- **Organização**: Listas sempre disponíveis
- **Praticidade**: Acesso de qualquer dispositivo
- **Educação Financeira**: Aprenda com seus hábitos
